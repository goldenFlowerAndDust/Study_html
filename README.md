# Study_html · 专升本学习站

这是一个可以直接双击使用的本地学习站：

- 英语：从空词库开始，添加单词后自动生成词卡、添加日志和复习队列。
- 数学：章节、公式、题库、思维导图全部保留；只清空了旧 AI 问答历史。
- 主页：根目录 `index.html`，GitHub Pages 打开时也是这个页面。

## 第一次使用

1. 双击 `配置API密钥.bat`，填入自己的 DeepSeek API Key。
2. 双击 `内容文件夹\专升本备考\备考专升本英语\启动词素服务.bat`。
3. 打开根目录 `index.html`，进入英语或数学。
4. 第一次添加单词后，复习清单会自动进入循环。

数学答疑需要时，双击：

```text
内容文件夹\专升本备考\备考专升本数学\启动数学答疑服务.bat
```

## 云端

`内容文件夹\专升本备考\共享配置\云端同步.json` 已指向腾讯云 SCF 代理。

第一次同步：

```text
双击 内容文件夹\专升本备考\同步全部科目.bat
```

云端待归档和复习队列已经清空。英语本地词库也是空的；不会自动带入旧单词。

## 文件说明

```text
index.html                         主页
内容文件夹\专升本备考\             英语、数学、共享配置
内容文件夹\自建本地网站\导航栏内容  英语/数学入口页
runtime\python                     便携 Python，BAT 优先使用
```

## 注意

- `API.txt`、`口令.txt`、`云端同步.json` 属于私人配置，不要提交到公开仓库。
- `runtime/` 是本地运行环境，不需要上传 GitHub。
- 英语旧词卡、旧答疑、添加日志已清空。
- 数学旧答疑、归档、原始问答日志已清空；数学正文资料保留。
