# Study_html · 专升本学习站

> **在线主页：** <https://goldenfloweranddust.github.io/Study_html/>

这是一个可以直接双击使用的本地学习站：

- 英语：从空词库开始，添加单词后自动生成词卡、添加日志和复习队列。
- 数学：章节、公式、题库、思维导图全部保留；只清空了旧 AI 问答历史。
- 编程：Python、JavaScript、HTML + CSS、MySQL、Node.js 五个方向。
- 三个 AI 答疑入口统一放在 `内容文件夹/AI答疑/`。
- 主页：根目录 `index.html`，GitHub Pages 打开时也是这个页面。

## 最近三天（2026-11-01 ~ 11-03）

- **新增编程 AI**：Python、JavaScript、HTML + CSS、MySQL、Node.js 五个方向。  
  入口：[编程语言 AI](内容文件夹/AI答疑/编程语言AI/index.html)
- **统一 AI 目录**：英语、数学、编程都收进 [AI答疑中心](内容文件夹/AI答疑/index.html)，启动、配置和同步放在一起。

  [worker.js](内容文件夹/AI答疑/共享工具/worker.js)
- **干净版**：本仓库不包含私人 API Key、云端令牌和历史记录，第一次使用先运行 `配置.bat`。

## 第一次使用

1. 首次先双击：

```text
内容文件夹\AI答疑\配置.bat
```

选 `1` 填 API Key，再选 `2/3` 填自己的云端地址和令牌。

2. 然后双击：

```text
内容文件夹\AI答疑\同步全部科目.bat
```

它会自动同步并启动三个服务。

3. 同步完成后会自动启动 8767 / 8768 / 8769 并打开：

```text
http://127.0.0.1:8769/AI答疑/
```

如果只想单独启动，可以双击 `打开AI答疑中心.bat`。

4. 打开根目录 `index.html`，进入英语、数学或编程。

5. 第一次添加单词后，复习清单会自动进入循环。

## 云端

云端地址和令牌需要由使用者自己填写，仓库里不包含任何私人云端配置。

首次同步：

```text
双击 内容文件夹\AI答疑\同步全部科目.bat
```

它会自动完成同步、启动服务和打开中心，不再需要选菜单。

云端待归档和复习队列已经清空。英语本地词库也是空的；不会自动带入旧单词。

### 查看配置 / 调整线路优先级

运行：

```text
配置.bat
```

选择：

```text
4. 查看当前配置 / 调整云端线路优先级
```

二级菜单会列出所有云端线路，第一条就是当前最先使用的线路。输入编号即可把该线路调整到第一位；输入 `0` 返回一级菜单。
